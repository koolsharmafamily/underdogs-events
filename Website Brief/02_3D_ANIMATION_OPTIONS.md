# 3D animation options
### Underdogs "Two Worlds" · the full menu, with your picks marked ★

**Your picks (10 Oct 2026):**
- **Structure:** Home plus two world pages.
- **Home:** a badge that re-skins.
- **The Red Room:** the room plus a smoke dragon.
- **Diwali:** the jewelled badge plus diyas.

The master prompt (`01_ANTIGRAVITY_MASTER_PROMPT.md`) builds the ★ options. Everything else here is a tested alternative you can swap in later.

**Phone cost** is how hard each option is on a mid-range phone: **Light** runs smoothly everywhere, **Medium** needs reduced particle counts, and **Heavy** needs a separate simplified mobile version.

**CD #** is the Claude Design prompt in `03_CLAUDE_DESIGN_3D_PROMPTS.md` that makes the 3D object it needs.

## How to swap an option later

Tell Antigravity, for example:

> *"Swap the Red Room main scene to option 6D (Mirror world) from 02_3D_ANIMATION_OPTIONS.md. Keep the badge, the transitions and all content unchanged."*

Each swap only replaces that scene's set or effect module. The badge, the scroll clock, the content file and the transitions stay as they are.
