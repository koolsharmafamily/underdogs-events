# Underdogs: "Two Worlds" website brief

These files describe a 3D, informative website for **Underdogs Entertainment (Nagpur)**. It has three pages: **Home**, **The Red Room** (Halloween) and **Diwali**. There is no booking and there are no outbound links.

| File | What it is |
|---|---|
| `01_ANTIGRAVITY_MASTER_PROMPT.md` | The full build brief. Save it as `BRIEF.md` in your Antigravity project. The kickoff message is at the top |
| `02_3D_ANIMATION_OPTIONS.md` | Every 3D direction considered; your picks are marked ★ |
| `03_CLAUDE_DESIGN_3D_PROMPTS.md` | Seven copy-paste prompts for Claude Design, one for each 3D object or effect |
| `reference/` | Cropped references to upload to Claude Design (badges, envelope, mirror and candles, posters) |

## Order of work

1. **Get the clean Underdogs logo** (SVG). The `Underdogs Logo.png` in this folder carries a watermark, so it's a reference only.
2. **Claude Design:** run Prompt 1 (the badge) first, then 2, 5, 6, 3, 4 and 7. Save the exports with the exact names given.
3. **Antigravity:** set up the project as described at the top of `01`, choose Gemini 3.8 Flash and Planning mode, and paste the kickoff message.

You can do 2 and 3 in parallel; the agent builds placeholders until the 3D files arrive.
